# Security policy
 
## Reporting a vulnerability
 
Please don't report security problems in public issues, discussions or pull requests.
 
Report them privately instead:
 
1. Open the **Security & quality** tab of this repository (on some screens it's called **Security**).
2. Select **Report a vulnerability**.
3. Describe the problem, the steps to reproduce it, and the possible impact.
 
This is a community sample, so there's no guaranteed response time, but every report is read.
 
## Supported versions
 
Only the latest release receives fixes.
 
## Scope
 
This project is a static web page plus a Teams app package. It doesn't store data or handle sign-in. Problems in Microsoft Teams, Microsoft 365, Azure or TeamsJS should be reported to the Microsoft Security Response Center at https://msrc.microsoft.com.
